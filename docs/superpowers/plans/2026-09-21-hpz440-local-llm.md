# HPZ440 Local LLM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an operations project for running a 7B-class local LLM on the HPZ440 LAN server with an RTX 3060 12GB GPU, exposing both an OpenAI-compatible API and Open WebUI.

**Architecture:** Use Docker Compose against the existing remote Docker context `hpz440`. Run a `llama.cpp` server container for GGUF inference and an Open WebUI container for browser chat, with PowerShell scripts on the Windows workstation driving lifecycle and validation.

**Tech Stack:** Docker CLI with remote context `hpz440`, Docker Compose, `llama.cpp` server image, Open WebUI image, PowerShell 7-compatible scripts, Markdown docs, self-contained PowerShell validation tests.

**Spec:** `docs/superpowers/specs/2026-09-21-hpz440-local-llm-design.md`

## Global Constraints

- Host: HPZ440 server on the LAN.
- GPU: NVIDIA RTX 3060 with 12GB VRAM.
- Model class: 7B models, preferably quantized GGUF files suitable for `llama.cpp`.
- Container runtime: use the existing remote Docker CLI context `hpz440`; do not rely on local Docker Desktop or local containers.
- Secrets, model files, generated logs, and benchmark artifacts must not be committed.
- Use PowerShell scripts for workstation operations.
- Do not expose the stack to the public internet.
- Do not commit during implementation unless the user explicitly asks.

## Review Focus

- Missing `.env`: lifecycle scripts should fail with a clear message telling the operator to copy `.env.example` to `.env`.
- Wrong Docker context: scripts should stop before running compose commands when the active context is not `hpz440`, unless the operator overrides through `DOCKER_CONTEXT`.
- Missing model file on the remote host: documentation and health checks should make the model placement requirement clear before users debug the wrong layer.
- Large/sensitive artifacts: `.gitignore` should exclude models, checkpoints, secrets, logs, generated benchmark output, and Open WebUI data.
- LAN URLs: docs and scripts should consistently use configurable host ports and avoid hard-coded public exposure.

```powershell
    [Parameter(Mandatory = $true)]

}

Set-Content -Path $EnvPath -Value $Lines
Write-Host "Updated LLM_MODEL_PATH=$ModelPath"
```

```powershell
[CmdletBinding()]
param(
    [string]$Prompt = 'Write one concise sentence about local LLM operations.',
    [int]$MaxTokens = 64
)

$ErrorActionPreference = 'Stop'
$Root = Split-Path -Parent $PSScriptRoot
$EnvPath = Join-Path $Root '.env'
if (-not (Test-Path $EnvPath)) { throw 'Missing .env. Copy .env.example to .env first.' }

$Values = @{}
Get-Content $EnvPath | Where-Object { $_ -match '^[A-Z0-9_]+=.*$' } | ForEach-Object {
    $Name, $Value = $_ -split '=', 2
    $Values[$Name] = $Value
}

$Port = if ($Values.LLM_HOST_PORT) { $Values.LLM_HOST_PORT } else { '8080' }
$OutputDir = Join-Path $Root 'benchmarks'
New-Item -ItemType Directory -Path $OutputDir -Force | Out-Null
$Stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
$OutputPath = Join-Path $OutputDir "benchmark-$Stamp.json"

$Body = @{
    model = 'local'
    messages = @(@{ role = 'user'; content = $Prompt })
    max_tokens = $MaxTokens
} | ConvertTo-Json -Depth 8

$Started = Get-Date
$Response = Invoke-RestMethod -Uri "http://localhost:$Port/v1/chat/completions" -Method Post -ContentType 'application/json' -Body $Body
$ElapsedMs = [int]((Get-Date) - $Started).TotalMilliseconds

@{
    prompt = $Prompt
    max_tokens = $MaxTokens
    elapsed_ms = $ElapsedMs
    response = $Response
} | ConvertTo-Json -Depth 16 | Set-Content -Path $OutputPath

Write-Host "Benchmark written to $OutputPath"
```

```markdown
# HPZ440 Local LLM

Operations project for serving 7B-class GGUF models from the HPZ440 LAN server with an RTX 3060 12GB GPU.

- `llama.cpp` server for an OpenAI-compatible API.

- API: `http://localhost:8080/v1`
- Open WebUI: `http://localhost:3000`

For LAN clients, replace `localhost` with the HPZ440 hostname or LAN IP.
```
